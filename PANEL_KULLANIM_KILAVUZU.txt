❓ PANEL NE YAPIYOV?
════════════════════════════════════════════════════════════════════════════════

Bu panel, GenAI Security Gateway'in admin kontrol merkezidir. Güvenlik ayarlarını
değiştirmek, sistem loglarını görmek ve tehlikeli kelime listesini yönetmek için
kullanılır.

KISA ÖZETİ:
• AI Layers (Katmanları) aç/kapat
• Confidence Threshold (hassasiyet) ayarla
• Kara liste (blacklist) yönet
• Sistem loglarını ve istatistikleri göz
• Yanlış engelleme bildir (feedback)

════════════════════════════════════════════════════════════════════════════════
🖥️ 3 SEKME NEDİR?
════════════════════════════════════════════════════════════════════════════════

1️⃣ DASHBOARD (Ana Sayfa)
   ├─ Toplam istekler: Kaç prompt işlenmiş
   ├─ Engellenen: Kaç zararlı istek yakalanmış
   ├─ İzin verilen: Kaç güvenli istek geçmiş
   ├─ Ortalama gecikme: Sistem kaç ms'de cevap veriyor
   ├─ Block/Allow oranı (grafik)
   ├─ Son istekler (tablo)
   └─ En son 10 log kaydı

2️⃣ LOGLAR (Detaylı İstek Kayıtları)
   ├─ Tüm istekleri filtreli şekilde görmek
   ├─ Filter seçenekleri:
   │  ├─ ALLOW / BLOCK (istekler geçti mi geçmedi mi?)
   │  └─ Category: Safe, Injection, Blacklist, PII, Policy Violation
   ├─ Log detayına tıkla → Modal açılır
   │  ├─ Log ID
   │  ├─ Zaman
   │  ├─ Kullanıcı
   │  ├─ Masked prompt (gizli veri maskelendi)
   │  ├─ Hangi katmanda durdu
   │  ├─ Engelleme nedeni
   │  └─ "Yanlış engelleme bildir" butonu

3️⃣ AYARLAR (Admin Kontrol Paneli)
   ├─ Layer Toggles (3 güvenlik katmanı aç/kapat)
   │  ├─ Layer 1: Regex + DLP (Veri Sızıntısı Engelleme)
   │  ├─ Layer 2: DeBERTa AI (Prompt Injection Tespiti)
   │  └─ Layer 3: LLM Judge (Jailbreak Analizi)
   ├─ AI Threshold Slider (0.0 - 1.0)
   │  ├─ Düşük (0.3): Hassas, yanlış pozitif çok
   │  ├─ Orta (0.65): Dengeli - TAVSİYE EDILEN
   │  └─ Yüksek (0.9): Çok katı, saldırı kaçabilir
   ├─ Kara Liste Yönetimi
   │  ├─ Yeni kelime ekle (input + "Kelime Ekle" buton)
   │  ├─ Varolan kelimeleri sil (her kelimenin yanında X)
   │  ├─ Kelimeler sistem tarafından otomatik engellenir
   │  └─ "Ayarları Kaydet" buton
   └─ Refresh Buton (sağ üst)
      └─ Dashboard'u 5 saniye aralıklarında otomatik yenile

════════════════════════════════════════════════════════════════════════════════
🎯 NASIL KULLANILIR?
════════════════════════════════════════════════════════════════════════════════

SENARYO 1: Zararlı kelime eklemek istiyorum
  1. AYARLAR sekmesine git
  2. "Kara Liste Yönetimi" bölümüne scroll et
  3. Input alanına kelime yaz (ör: "bomba", "exploit", "malware")
  4. "Kelime Ekle" buton'a tıkla
  5. Kelime listeye eklenir ve sistem otomatik engeller
  6. "Ayarları Kaydet" buton'a tıkla

SENARYO 2: Sistem çok katı/çok toleranslı mi?
  1. DASHBOARD'a git
  2. Engellenen/İzin verilen oranına bak
  3. AYARLAR'a git
  4. AI Threshold sliderı kaydır:
     └─ Sola kaydır (0.3): Daha hassas, daha çok engelle
     └─ Sağa kaydır (0.9): Daha toleranslı, daha az engelle
  5. "Ayarları Kaydet" buton'a tıkla

SENARYO 3: Hangi istekler engellendi görmek istiyorum
  1. LOGLAR sekmesine git
  2. "BLOCK" buton'una tıkla (sadece engellenen istekleri göster)
  3. Bir log'a tıkla → detay modal açılır
  4. Engelleme nedenini oku
  5. Eğer yanlış engellenmişse: "Yanlış Engelleme Bildir" buton'u tıkla

SENARYO 4: Layer 2 (DeBERTa) kapalı mı?
  1. AYARLAR sekmesine git
  2. Layer 2 toggle'ına bak
     └─ Kırmızı/OFF = Kapalı (Windows MKL sorunu nedeniyle)
     └─ Yeşil/ON = Açık
  3. ⚠️ Şu anda Windows'ta Layer 2 disable edilmiş (DeBERTa model sorunu)
     Bunun yerine Layer 1 (regex) ve Layer 3 (LLM) aktif

⚙️ TEKNIK BİLGİLER (DEVELOPERs İÇİN)
════════════════════════════════════════════════════════════════════════════════

BACKEND API ENDPOİNTLERİ:

GET /api/v1/config
  └─ Şu anki settings'i JSON olarak döner

PUT /api/v1/config/threshold?threshold=0.65
  └─ AI hassasiyet değerini güncelle

PUT /api/v1/config/layers?layer1=true&layer2=true&layer3=false
  └─ Katmanları aç/kapat

PUT /api/v1/config/blacklist?operation=add&word=KELIME
  └─ Kara listeye kelime ekle

PUT /api/v1/config/blacklist?operation=remove&word=KELIME
  └─ Kara listeden kelime sil

GET /api/v1/logs?limit=50&action=BLOCK&category=Injection
  └─ Logları filtrele

GET /api/v1/stats
  └─ İstatistikler

POST /api/v1/feedback?log_id=ID&feedback_type=false_positive
  └─ Geri bildirim kaydet
