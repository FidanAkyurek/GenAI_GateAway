──────────────────────────────────────────────────────────
Durumu: Layer 2 kullanılabilir ama Windows MKL crash'ı nedeniyle disable edildi

Neden?

- NumPy + MKL (Math Kernel Library) entegrasyonu problemi
- Error: "forrtl: error (200): program aborting due to control-C event"

Çözüm (Uygulanan):
- app/main.py: "from app.services.layer2_deberta import Layer2DeBERTa" → comment edildi
- app/controllers/security_controller.py: Layer2DeBERTa calls → disable edildi
- Placeholder: ai_score = 0.0 (dummy değer)

İmprove Gereken:
□ NumPy/MKL'yi tamamen kaldırmak ya da CPU-only mode kurmak
□ DeBERTa modelini lazy loading ile çalıştırmak
□ Linux/Docker ortamında test etmek (MKL problemi Windows-specific)
